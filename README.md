# Win11-Tweaks

Интерактивный PowerShell-скрипт с удобными твиками для Windows 11. Выберите нужные пункты в меню, и скрипт применит их. Любой твик можно откатить обратно.

- Без установки и без скачивания чего-либо из сети
- Открытый код без обфускации (один файл `.ps1`)
- Автоматический запрос прав администратора
- Точка восстановления перед первым применением
- Откат любого твика одной командой

---

## Требования

- Windows 11
- Windows PowerShell 5.1 (встроен в систему)
- Права администратора (скрипт запросит их сам)

> **Проверено на:** `Windows 11 Home (25H2)`
> Работоспособность отдельных твиков зависит от сборки Windows: Microsoft периодически защищает или меняет параметры реестра.

---

## Быстрый старт

1. Скачайте `Win11-Tweaks.ps1` из раздела [Releases](../../releases).
2. Запустите скрипт: 
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\Win11-Tweaks.ps1
   ```
3. Подтвердите запрос UAC.

Перед запуском рекомендую прочитать код: скрипт меняет системные настройки.

---

## Как пользоваться

В меню отображается нумерованный список твиков. Вводите команды:

| Ввод | Действие |
|------|----------|
| `1,3,5` | Применить твики 1, 3 и 5 |
| `2-6` | Применить твики с 2 по 6 |
| `A` | Применить все |
| `U 1,3` | Откатить твики 1 и 3 |
| `U A` | Откатить все |
| `Q` | Выйти |

После применения проводник перезапускается автоматически (если твик этого требует). Часть изменений (быстрый запуск, телеметрия, политики) вступает в силу после перезагрузки.

## Безопасность

- Скрипт **не скачивает** файлы и **не обращается к сети**.
- Он **не удаляет** файлы и программы, не отключает службы и антивирус.
- Меняются только значения реестра, схема питания и режим гибернации.
- Перед первым применением создаётся **точка восстановления** (Windows ограничивает их частоту: не чаще одной за 24 часа).

### Важно знать

- **Откат возвращает значения Windows по умолчанию**, а не ваши прежние настройки. Если вы вручную меняли какой-то параметр, после отката он станет стандартным.
- **Точка восстановления** лучше защищает системные настройки, чем пользовательские. Для пользовательских твиков опирайтесь на откат через `U`.
- Политики (виджеты, Copilot, Bing, телеметрия, история действий) могут вызвать надпись «Некоторыми параметрами управляет ваша организация» в «Параметрах».
- Гибернация и быстрый запуск связаны: после отключения гибернации быстрый запуск работать не будет.
- «Высокая производительность» увеличивает расход батареи. На устройствах с Modern Standby этой схемы может не быть: команда завершится ошибкой, но системе это не навредит.
- Если скрипт запущен под другой учётной записью администратора, пользовательские настройки (`HKCU`) применятся к ней, а не к вашему пользователю.
- Крупные обновления Windows могут сбросить часть настроек. Достаточно запустить скрипт повторно.
- На редакциях Home/Pro телеметрию полностью отключить нельзя: останется базовый уровень.

## Известные ограничения

- **Виджеты:** на некоторых сборках Windows 11 ключ политики защищён от записи, и твик завершается ошибкой. Скрипт пробует запасной способ, но если и он не сработает, отключите виджеты вручную: **Параметры → Персонализация → Панель задач → Виджеты → Выкл.**
- **Copilot:** на новых сборках политика может не действовать, так как Microsoft меняет реализацию Copilot.

## Вопросы и ответы

**Нужно ли применять всё сразу?**
Нет. Безопаснее выбирать нужные пункты и проверять результат, особенно для политик и твиков питания.

**Как вернуть всё как было?**
Запустите скрипт, введите `U A`, затем перезагрузите компьютер.

**Скрипт запрашивает права администратора. Это нормально?**
Да, часть твиков изменяет системные ключи реестра (`HKLM`) и схему питания. Код открыт, проверьте его перед запуском.

**Скрипт вывел ошибку у одного из пунктов.**
Остальные твики при этом применяются независимо. Откройте [Issue](../../issues) и укажите версию Windows, номер сборки (`winver`) и текст ошибки.
